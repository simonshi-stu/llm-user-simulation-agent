# Public Status — 2026-10-28

## Scope

This report covers the generation-side publication in this repository and the
source-only checks completed in the private development workspace. Raw data,
target labels, prompts, model outputs, and per-record results remain in
Drive/Colab and are not included here.

## Verified results

- Runner version: `amazon-raw-full-temporal-v2`.
- The Amazon Musical Instruments source-only dry-run parsed `3,017,439` rows.
- `3,017,381` rows were valid and `58` were explicitly rejected as
  `invalid_timestamp`.
- Valid normalized dates ranged from `2001-09-17` through `2023-09-12`.
- The adapter accepts the legacy/new field layouts and second, millisecond,
  microsecond, and nanosecond epoch timestamps.
- Offline checks cover parser smoke cases, time-safe context construction,
  rating baselines, transport-failure isolation, and successful-output-only
  Memory writes.
- The public repository's offline suite passed `186` tests; no real model was
  called during that validation.

These are source and engineering checks. They are not full-model accuracy,
style, cost, latency, or Memory-benefit results.

## Evaluation boundary

The historical 400-task numbers remain historical sample results, not full raw
dataset results. A prior DeepSeek run was stopped before completion and is not
reported as a benchmark; it produced no complete `summary.json` or `report.md`.
The next full evaluation is planned with the current GPT-5.6 Luna model in
max/Absolute mode, after a private batch interface, data-transfer approval,
budget, and stop conditions are available. DeepSeek will not be used for that
full evaluation.

## A/B consolidation

The development workspace was used to check one workflow containing:

- Agent A generation: profiling, reference selection, reflection/repair,
  temporal safety, in-run Memory, Amazon normalization, and deterministic
  baselines.
- Project B evaluation: versioned result contracts, independent scoring,
  coverage/failure diagnostics, evidence checks, and export acceptance.

This is a reviewed source-snapshot consolidation, not a merge of the two Git
histories. Project B remains at
<https://github.com/simonshi-stu/amazon-instruments-evaluation-agent>; this
repository publishes the generation side and public documentation.
